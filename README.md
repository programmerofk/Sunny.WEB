# ☀️ Ясно — Погодное веб-приложение

Современное, минималистичное приложение для прогноза погоды, выполненное в стиле Glassmorphism (эффект матового стекла). Проект написан на чистом HTML, CSS и JavaScript без использования сторонних фреймворков и библиотек.

## 🔗 Демо

- [Посмотреть сайт (GitHub Pages)](#) _(добавьте ссылку после публикации)_

## 🛠 Технологии

- **HTML5** (семантическая разметка)
- **CSS3** (CSS Grid, Flexbox, CSS-переменные, `backdrop-filter` для эффекта стекла)
- **Vanilla JavaScript** (ES6+, Async/Await, Fetch API, работа с DOM, `localStorage`)
- **API:** [Open-Meteo](https://open-meteo.com/) (бесплатный прогноз погоды и геокодинг без API-ключа)
- **Иконки:** OpenWeatherMap (CDN)
- **Шрифт:** Inter (Google Fonts)

## ✨ Функционал

**Интеграция с API и данные:**

- **Поиск по городу:** Напишите название города на английском или русском, и приложение найдет его координаты через Geocoding API и запросит погоду.
- **Геолокация:** Кнопка «Моё местоположение» запрашивает координаты у браузера и показывает погоду для текущей локации.
- **Сохранение последнего города:** Приложение запоминает, какой город вы искали последним, и загружает его при следующем открытии страницы (через `localStorage`).
- **Динамический график температуры:** В блоке «По часам» SVG-график автоматически перерисовывается в зависимости от реальных температурных данных.

**Интерфейс и UX:**

- **Светлая и темная темы:** Переключение по кнопке с сохранением выбора. При смене темы меняются цвета стекла, текста и фоновых пятен (blobs).
- **Слайдеры:** Кнопки-стрелочки плавно прокручивают 24-часовой прогноз и список дней в блоке «На 5 дней».
- **Адаптивность:** Сайт отлично выглядит на больших экранах (ПК), планшетах и смартфонах.
